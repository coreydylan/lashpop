**Subject:** Your new LashPop Studios website is live 🎉

Hi Emily and team,

Congratulations — the new LashPop Studios website is officially live!

**Website:** https://lashpopstudios.com

Here are the important handoff details to keep handy:

### Website admin

You can manage the website at:

**Admin panel:** https://lashpopstudios.com/admin/login

Sign in with your approved mobile number and the one-time verification code sent by text. Inside the admin panel, you can update website content, services, team information, photos, reviews, quiz content, and view newsletter signups and Work With Us submissions.

There is also a searchable help guide inside the admin panel:

**Help guide:** https://lashpopstudios.com/admin/owner-guide

The guide should be ready to use, although I still want to give it one final fine-tooth-comb review. If anything is unclear or does not match what you see, just ask me and I will help.

### Hosting plan

You can return to the Clarity Kit link you already received to select your hosting plan and finish that process. If you have trouble reopening it or are unsure which option to choose, let me know before submitting anything.

### Domain and DNS

LashPop Studios' DNS is currently hosted in my Cloudflare account. If you ever need to make a domain or DNS change—or receive a domain-related notice you are unsure about—please send it to me first so I can make sure the website, email, and verification records remain protected.

The website application is hosted on Vercel, while Cloudflare handles DNS and the site's image delivery infrastructure. You do not need to manage those technical systems yourself.

### Form-notification verification

You will receive a verification email from Cloudflare after launch. Please click the verification link when it arrives. That approval allows the website to send new form-submission notifications to your inboxes.

The submissions themselves are saved in the Admin Inbox before any notification is attempted, so the admin panel remains the source of truth for Work With Us applications and newsletter signups.

### Bookings and website updates

Appointments continue to be completed through Vagaro. For new services or team members, make the change in Vagaro first, then use the website admin workflow or contact me so the public website and booking links remain in sync.

### Analytics and future advertising

The site includes privacy-friendly Vercel Web Analytics and Speed Insights so we can review aggregate traffic, popular pages, referral sources, device types, booking starts, quiz completions, Work With Us applications, and newsletter signups. These analytics do not include visitor names, email addresses, phone numbers, application text, or quiz answers.

Google Tag Manager and the Meta Pixel are preserved but intentionally turned off because LashPop is not currently advertising. If you decide to run Google or Meta ads later, please contact me before the campaign starts. I can activate the appropriate campaign tracking and consent controls without rebuilding the site.

I am keeping the previous Squarespace setup available during the initial observation period as a rollback safeguard. If you notice anything unexpected, send me the page link, a screenshot, and a quick description of what happened.

Congratulations again. I am excited to see the new site out in the world!

Corey
